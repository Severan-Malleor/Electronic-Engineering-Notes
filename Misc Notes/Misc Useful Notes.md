# Forward Voltage
Forward voltage is the specific voltage drop across the LED when it is conducting current normally.

### The Voltage Drop Breakdown

- **Fixed Drop**: The LED will always "consume" or drop exactly its forward voltage (1.8V) from the power source.
- **The Remainder**: The remaining voltage (5V - 1.8V = 3.2V) must drop across the rest of the circuit.
- **The Resistor's Job**: Because a wire has almost zero resistance, a resistor is added so that the remaining 3.2V drops safely across it instead of overloading the LED.

### Unit Conversion Rule (Metric Prefixes)

**Core Idea:**

- **Multiply** → Number gets **bigger**, Prefix gets **smaller** (e.g., A → mA)
- **Divide** → Number gets **smaller**, Prefix gets **bigger** (e.g., mA → A)

**Mnemonic:** 
**"Smaller unit = Bigger number"**
**"Bigger unit = Smaller number"**
